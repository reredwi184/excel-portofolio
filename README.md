# Customer Orders Portofolio Project
## Project Overview
This project analyzes a dataset Customer Orders using Microsoft Excel.
## Dataset
The dataset contains order-level sales records with fields such as transaction ID, order date, customer name, region, channel, delivery status, product category, order value, and satisfication. Data will be displayed in PivotTables and Power Pivot.
## Tools Use
- Microsoft Excel
- Excel formulas
- Summary tables
- PivotTable-style analysis
- Excel dashboard
- GitHub documentation
## Analysis Process
1. Reviewed raw sales order data and data dictionary.
2. Standardized text fields such as region, customer segment, date, and product category.
3. Converted date and numeric fields into analysis-ready values.
4. Reviewed duplicate orders, missing values, and unusual status records.
5. Built summary analysis for order value, shipping fee, order count, sum order value.
6. Created a dashboard preview and business insights.
